The System

Three parts, working as one.

Every alert starts as raw location data and ends as a message on a parent's phone. Here's how it moves through the system, step by step.

Step 01
📡

Satellite Acquisition

The Tracker. The wearable tracker uses a Neo-6M GPS module to communicate with overhead satellites, determining the user's precise latitude and longitude coordinates.

Step 02
☁️

Cloud Syncing

The Data Bridge. The onboard ESP32 microcontroller packages these coordinates and uses Wi-Fi to continuously stream the live data to our Node.js backend server, hosted on Render.

Step 03
💻

Geofence Verification

The Website. This live tracking website pulls the coordinates straight from the database in real time. It continuously calculates the physical distance between the tracker and the center of your pre-set "Safe Zone" to detect breaches.

Core Features

Built to be simple for parents and reliable for the people responsible for getting kids home safely.

01 Real-Time GPS Tracking Delivers precise, active coordinate updates with minimal latency.
02 Dynamic Geofencing Allows supervisors to establish a virtual boundary around any location (like a school or home) with a customizable safety radius.
03 Instant Safety Alerts Priority Triggers immediate browser and system-level notifications the exact second a boundary is crossed.
04 Low-Power Wearable Architecture Built on highly energy-efficient hardware, making the tracker compact and easy to carry.
